# 🎓 Student Performance Analysis & Prediction

A Streamlit-based Student Performance Analysis & Prediction project developed using Python, Pandas, data visualization, and machine learning.

## 🚀 Features

- 📂 Upload CSV/Excel student datasets
- 🧹 Data cleaning and preprocessing
- 🔍 Missing value handling
- ♻️ Duplicate record removal
- 📊 Exploratory Data Analysis (EDA)
- 📚 Study time analysis
- 🏫 Attendance analysis
- 📈 Previous score analysis
- 👨‍👩‍👧 Parental education analysis
- 🌐 Internet access analysis
- 🏆 Extracurricular activity analysis
- 🔥 Correlation heatmap
- 🤖 Machine learning prediction
- 📊 Model comparison
- 🎯 Actual vs Predicted score visualization
- ⭐ Feature importance analysis
- 💡 Academic performance insights
- ⬇️ Download cleaned dataset and results

## 🤖 Machine Learning Models

The project compares:

1. Linear Regression
2. Random Forest Regressor
3. Gradient Boosting Regressor

### Evaluation Metrics

- MAE – Mean Absolute Error
- MSE – Mean Squared Error
- RMSE – Root Mean Squared Error
- R² Score
